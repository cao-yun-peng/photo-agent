# 搜索 Agent 体验优化评估

| 优化项 | 收益 | 难度 | 决策 |
| --- | --- | --- | --- |
| 新/替换搜索即时清空旧结果 | 高 | 低 | 本轮实现 |
| 明确拒绝某张结果并加入会话排除集 | 高 | 中 | 本轮实现 |
| 负反馈对象不唯一时按序号澄清 | 高 | 低 | 本轮实现 |
| 保存结构化、脱敏的反馈 trace | 中高 | 中 | 本轮实现 |
| 旧会话已选照片的工作流状态恢复 | 高 | 低 | 本轮实现 |
| 丢失“那张照片”上下文时主动澄清 | 高 | 低 | 本轮实现 |
| 反馈原因标签（人物错、时间错、内容错、质量差） | 高 | 中 | 下一批；先收集受控标签 |
| 用反馈集离线回放并调优快速路由/召回 | 高 | 中 | 下一批；需要样本量和基线 |
| 对一批结果启动视觉模型二次筛查 | 中高 | 高 | 条件触发；需费用、延迟与准确率门禁 |
| 跨会话长期偏好自动学习 | 中 | 高 | 暂缓；需用户控制、删除、保留期和误泛化评估 |
| 结果集版本号与历史结果折叠/切换 | 中 | 中 | 可作为后续前端体验项 |

本轮采用“确定性规则和状态修复优先、Prompt 负责剩余歧义”的实现顺序。反馈 trace 不直接改变
全局检索策略；后续应先从结构化事件构造开发集，离线验证收益后再灰度发布。
