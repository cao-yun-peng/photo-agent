## 项目目标

- 为中文用户提供从照片上传、视觉理解、自然语言检索到 Agent 辅助选图和受确认图像生成的闭环。
- 在用户隔离、权限、预算、幂等、失败关闭和隐私边界内提供可复现、可观测、可回滚的 Agent 能力。
- 以新鲜评测和端到端证据决定是否进入发布阶段，不把历史演示结果当作当前发布证明。

## 范围

### 包含

- Web 与微信小程序的认证、照片上传、时间线、搜索、Agent 和生成体验。
- FastAPI、PostgreSQL/pgvector、Redis/ARQ、对象存储及相关异步处理。
- Qwen VL、Embedding、Chat、通义万相和 OpenAI Images 的受控适配与 Mock 降级。
- Agent 状态机、有限工具循环、SSE、预算、安全策略、评测、可观测性和运维。

### 非目标

- 未经用户确认执行付费或高影响图像生成动作。
- 让 LLM 直接访问数据库、Redis、对象存储凭据或绕过确定性权限规则。
- 在缺少真实用户数据和发布证据时宣称达到生产泛化质量。
- 当前阶段不承诺 ASR、无限自主规划或多 Agent 架构。

## 技术路线与关键约束

- 保持单层、有限步数的 Agent 编排；确定性代码拥有权限、状态、预算和业务不变量。
- 大文件通过签名 URL 直传；所有资源查询必须绑定 JWT 用户所有权。
- 高成本生成执行“准备 → 摘要 → 用户确认 → 幂等入队”，并实施额度预占与失败释放。
- 模型输出和项目文件均视为不可信输入；Schema 校验、超时、熔断、重试和降级必须由系统执行。
- Prompt、工具 Schema、模型、评测集和发布配置必须版本化；Gate 证据绑定 Git SHA 或文件哈希。

## 数据与安全边界

- 数据分类：用户照片、视觉描述、搜索内容、会话状态和生成结果属于敏感用户数据。
- 治理文档只保存脱敏摘要、证据 ID、相对路径、Git SHA 和文件哈希。
- 生产环境必须关闭开发登录和 Mock 配置，使用密钥托管、HTTPS、受限 CORS、最小权限和审计。
- 生产阻塞项以 `docs/09-observability-and-security.md` 和 `PROJECT_PROGRESS.md` 的当前记录为准。
