# 项目功能

> 功能范围与状态的唯一清单。现有代码和文档证明功能已实现到一定程度，但在取得当前 Git SHA 对应的新鲜证据前不标记为“已完成”。

## 状态定义

- 候选：尚未批准进入范围
- 已规划：已确认但未开始
- 进行中：已有实现，仍需当前版本验证或收尾
- 已阻塞：等待外部条件或阻断风险关闭
- 已完成：完成条件已满足且有新鲜证据
- 已取消：明确退出范围并保留原因
