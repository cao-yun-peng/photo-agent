# P2：反馈驱动的分级搜索

2026-09-06，任务 S6-P2-001。实现位于当前工作树，尚未发布。

## 用户行为

- 单张否定只排除该照片；“太少了”“还有吗”继续搜索，不累计不满。
- 同一目标下第一次整批否定加强校验；第二个不同结果批次仍被否定时，尝试保留日期、标签等条件的候选浏览，并明确候选未经语义匹配确认。
- 含必须满足的视觉或否定条件，或者没有可保留的结构条件时，拒绝自动放宽。原预算、用户范围和排除项继续有效。
- 全相册浏览由“浏览全部相册”等明确指令触发，使用游标分页；模型服务故障不再自动打开全相册。
- 换目标重置计数；肯定结果清零；重复或过期批次反馈不升级。进入候选浏览后继续不满也不自动扩大到全部照片。

## 实现与兼容

规则路由先处理明确反馈和换目标；无法判定时，上下文分类器仅在存在当前结果且置信度至少0.85时接受整批反馈。模型输出不负责指定反馈照片或控制计数。

AgentState新增可选持久状态search_feedback。成功且非空的结果附result_batch_id、search_goal_id、browse_scope；Web和小程序回传可选feedback_batch_id。批次身份由服务端目标、范围和有序照片集合生成。同批重复不计数，历史身份最多保留64批，达到上限拒绝继续计数。旧会话可恢复，无数据库迁移。

旧客户端未回传批次时按当前批次处理，因此无法可靠区分其延迟提交与新反馈；需同步更新客户端才能获得完整防过期保护。旧搜索会话缺少计划时第一次只安全续搜，第二次不会无条件扩大范围。
